## ขั้นที่ 1 — วางไฟล์รูปในโฟลเดอร์ website

ลากรูปมาวางในโฟลเดอร์เดียวกับไฟล์ .html นี้เลย (โฟลเดอร์ `website/`)

| หน้า | ไฟล์ที่ต้องแก้ | ชื่อรูปแนะนำ | รูปที่เหมาะ |
|---|---|---|---|
| เคส 01 Content | `work-01.html` | `case01.jpg` | thumbnail The Health Visionary / เฟรมคลิป |
| เคส 02 B2B | `work-02.html` | `case02.jpg` | หน้า Health Design Center / ภาพจากบทความ |
| เคส 03 LINE OA | `work-04.html` | `case04.jpg` | แบนเนอร์ Agnos x กทม. / rich menu |

## ขั้นที่ 2 — แก้ HTML: เปลี่ยนภาพ SVG เป็นรูปจริง

เปิดไฟล์ .html ด้วย TextEdit หรือ VS Code แล้ว **ลบทั้งบล็อก `<svg class="cover">…</svg>`**
(เริ่มจากบรรทัด `<svg class="cover"` ยาวไปจนถึง `</svg>`) แล้วพิมพ์แทนด้วยบรรทัดเดียวนี้:

```html
<img class="cover" src="case01.jpg" alt="ชื่อภาพ">
```

เปลี่ยน `case01.jpg` เป็นชื่อไฟล์รูปของหน้านั้น

**สำคัญ:** แต่ละหน้ามีภาพ cover **2 จุด** (บล็อกภาษาไทย 1 + ภาษาอังกฤษ 1) — ต้องแก้ทั้งสองจุดในไฟล์เดียวกัน
บรรทัด `<p class="figure-note">…</p>` ที่อยู่ใต้ SVG จะลบทิ้งด้วยก็ได้ (มันคือโน้ตเตือนเฉยๆ)

---

## ตัวอย่าง (เคส 01)

**ก่อน:**
```html
<svg class="cover" viewBox="0 0 800 420" ...>
  ... หลายบรรทัด ...
</svg>
<p class="figure-note">...swap with a real photo...</p>
```

**หลัง:**
```html
<img class="cover" src="case01.jpg" alt="The Health Visionary">
```

เท่านี้เสร็จ เปิดไฟล์ในเบราว์เซอร์เช็กได้เลย

## ใส่หลายรูปในหน้าเดียว

ใส่กี่รูปก็ได้ เลือกวางได้ 2 แบบ ผสมกันในหน้าเดียวก็ได้

### แบบ A — รูปใหญ่เรียงลงมา (เหมาะกับภาพหลัก / screenshot หน้าเว็บ)
เพิ่มหลายบรรทัดต่อกัน:
```html
<img class="cover" src="case02-a.jpg" alt="ภาพหลัก">
<img class="cover" src="case02-b.jpg" alt="ภาพที่ 2">
```

### แบบ B — แกลเลอรีเรียงเป็นแถว (เหมาะเวลามีหลายรูปเล็กๆ เช่น ภาพอีเวนต์)
ครอบรูปด้วย `<div class="figrow">`:
```html
<div class="figrow">
  <img src="case02-c.jpg" alt="ภาพ 1">
  <img src="case02-d.jpg" alt="ภาพ 2">
  <img src="case02-e.jpg" alt="ภาพ 3">
</div>
```
> ใส่กี่รูปใน figrow ก็ได้ ระบบจัดขึ้นบรรทัดใหม่ให้เอง (2–3 รูป/แถว บนจอใหญ่)

### ผสมกัน — วางไล่ตามลำดับได้เลย
```html
<img class="cover" src="hero.jpg" alt="ภาพเปิด">      <!-- รูปใหญ่นำ -->
<div class="figrow">                                   <!-- ตามด้วยแถวรูปเล็ก -->
  <img src="a.jpg" alt=""><img src="b.jpg" alt=""><img src="c.jpg" alt="">
</div>
```

**ชื่อไฟล์:** จะตั้งอะไรก็ได้ ขอแค่ตรงกับใน src เช่น `case02-a.jpg`, `event-stage.jpg`
**อย่าลืม:** แต่ละหน้ามี 2 บล็อก (ไทย/อังกฤษ) ถ้าอยากให้โชว์ทั้งสองภาษาต้องใส่ทั้งสองจุด

## ใส่รูป thumbnail การ์ดในหน้า Home

หน้าแรก (`index.html`) การ์ดเคสแต่ละใบมีกล่องภาพ `<div class="gthumb ...">`
แค่หยอด `<img>` เป็นบรรทัดแรกในกล่องนั้น รูปจะเต็มพื้นหลังการ์ด ตัวหนังสือลอยทับให้อัตโนมัติ
(ระบบใส่เงาดำจาง + เปลี่ยนตัวอักษรเป็นสีขาวให้เอง เพื่อให้อ่านออกบนรูป)

**ก่อน:**
```html
<div class="gthumb c-content">
  <span class="cat" data-lang="th">Content Strategy</span>...
  <span class="big" data-lang="th">190K+ views...</span>...
</div>
```

**หลัง (เพิ่มแค่บรรทัด `<img>`):**
```html
<div class="gthumb c-content">
  <img src="thumb-01.jpg" alt="">
  <span class="cat" data-lang="th">Content Strategy</span>...
  <span class="big" data-lang="th">190K+ views...</span>...
</div>
```

การ์ดทั้ง 4 ใบอยู่ในไฟล์ `index.html` (ค้นคำว่า `gthumb`) — วางรูปในโฟลเดอร์ website แล้วเพิ่ม `<img>` ในแต่ละใบ
> การ์ดหน้า Home มีจุดเดียวต่อใบ (ไม่มีบล็อกไทย/อังกฤษแยก) แก้ครั้งเดียวจบ

## ทางที่ง่ายกว่า

ถ้าไม่อยากแก้ HTML เอง — แค่วางรูป (ขั้นที่ 1) ในโฟลเดอร์ website ให้ครบ แล้วบอกเรา
พร้อมบอกคร่าวๆ ว่าหน้าไหนอยากได้กี่รูป แบบใหญ่หรือแบบแถว เดี๋ยวเราจัดให้ทุกจุดในครั้งเดียว
